### 優先度表示

ドキュメント内で以下の優先度表示を使用：

- ⭐⭐⭐ - 必読ドキュメント
- ⭐⭐ - 重要ドキュメント
- ⭐ - 参考ドキュメント

改善提案の優先度：

- **P0 (Critical)** - 重大な問題、即座に対処が必要
- **P1 (High)** - 高優先度、システムを大幅に向上
- **P2 (Medium)** - 中優先度、機能を改善
- **P3 (Low)** - 低優先度、付加価値

## 🎯 主要機能

### コア機能

- ✅ **リアルタイムストリーミング対話** - Server-Sent Events 実装
- ✅ **RAG ナレッジベース** - Qdrant ベクトル検索
- ✅ **マルチ LLM サポート** - OpenAI、Anthropic、カスタム API
- ✅ **ユーザー権限管理** - JWT + RBAC
- ✅ **セッション管理** - 永続化ストレージと検索

### 技術ハイライト

- 🚀 **非同期アーキテクチャ** - FastAPI + asyncio
- 🎨 **モダンフロントエンド** - React 18 + TypeScript + Material-UI
- 🐳 **コンテナ化デプロイ** - Docker Compose ワンクリックデプロイ
- 📊 **可観測性** - ヘルスチェックとログシステム

## 🔧 技術スタック

### バックエンド

- Python 3.10+
- FastAPI 0.116.1
- LangChain 0.3.27
- SQLAlchemy 2.0.36
- Qdrant Client 1.10.1

### フロントエンド

- React 18.2.0
- TypeScript 4.9.5
- Material-UI 5.14.1

### インフラストラクチャ

- MySQL 8.0
