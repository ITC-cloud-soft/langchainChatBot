# langchainChatBot 项目概述

## 📋 项目简介

langchainChatBot 是一个基于 **FastAPI** 和 **React** 的企业级智能聊天机器人系统，集成了 LangChain、Qdrant 向量数据库和 MySQL 关系数据库，提供完整的 RAG（检索增强生成）功能。

### 核心特点

- 🏢 **单租户设计** - 专为单一组织设计，架构简洁易维护
- 💬 **实时流式对话** - 支持流式响应，提供流畅的用户体验
- 🤖 **灵活的 LLM 集成** - 支持 OpenAI、Anthropic、Google Gemini 及自定义 API
- 📚 **知识库管理** - 支持多种文档格式，基于向量检索的智能问答
- 👥 **用户权限管理** - 基于角色的访问控制（RBAC）
- 🔐 **JWT 认证** - 安全的 Token 认证机制，支持自动刷新
- ⚙️ **热重载配置** - config.toml 配置文件修改即时生效

## 🔑 核心功能模块

### 1. 认证与授权模块

- **JWT Token 认证**
  - Access Token (30分钟有效期)
  - Refresh Token (7天有效期)
  - 自动 Token 刷新机制
  
- **角色权限管理**
  - Admin: 完全访问权限（用户管理、系统配置、知识库管理）
  - User: 基础聊天功能

- **密码安全**
  - bcrypt 加密存储
  - 密码强度验证

### 2. 聊天对话模块

- **实时流式响应**
  - Server-Sent Events (SSE) 实现
  - 逐字符流式输出
  - 支持中断和重试

- **会话管理**
  - 多会话支持
  - 会话历史持久化
  - 会话搜索和过滤

- **上下文管理**
  - 对话历史记忆（可配置最大历史条数）
  - 上下文缓存优化
  - 智能上下文截断

### 3. RAG 知识库模块

- **文档处理**
  - 支持格式: PDF, TXT, DOCX, MD
  - 文档分块（Chunking）
  - 元数据提取

- **向量检索**
  - Qdrant 向量数据库
  - 语义相似度搜索
  - 混合检索策略

- **Embedding 生成**
  - Ollama 本地模型
  - OpenAI Embedding API
  - 可配置维度（默认 768）

### 4. LLM 配置模块

- **多提供商支持**
  - OpenAI (GPT-3.5, GPT-4)
  - Anthropic (Claude)
  - Google (Gemini)
  - 自定义 API（兼容 OpenAI 格式）

- **参数调优**
  - Temperature (创造性控制)
  - Max Tokens (输出长度)
  - Top P (核采样)
  - Frequency/Presence Penalty (重复控制)

- **配置管理**
  - 热重载配置
  - 配置导入/导出
  - 连接测试功能

### 5. 用户管理模块

- **用户 CRUD**
  - 创建、读取、更新、删除用户
  - 批量操作支持
  - 用户搜索和过滤

- **权限控制**
  - 角色分配
  - 账户启用/禁用
  - 密码重置

- title: VARCHAR(200)
- is_active: BOOLEAN

#### chat_messages 表
```sql
- id: INT (主键)
- session_id: VARCHAR(100) (外键)
- role: ENUM('user', 'assistant', 'system')
- content: TEXT
- message_type: VARCHAR(50)
- timestamp: DATETIME
- source_documents: JSON
- error_info: JSON
```

```python

- Payload:
  - content: str (文档内容)
  - metadata: dict (文档元数据)
    - filename: str
    - file_type: str
    - upload_time: str
    - chunk_index: int
```

## 🔄 数据流程

### 聊天对话流程

```
1. 用户输入消息
   ↓
2. Frontend 发送 POST /api/chat/stream
   ↓
3. Backend ChatService 处理
   ↓
4. 检索相关知识（Qdrant 向量搜索）
   ↓
5. 构建提示词（Prompt Template）
   ↓
6. 调用 LLM API（流式响应）
   ↓
7. 实时返回 Token 流
   ↓
8. 保存对话历史（MySQL）
   ↓
9. Frontend 渲染消息
```

### 知识库上传流程

```
1. 用户上传文档
   ↓
2. Frontend 发送 POST /api/knowledge/documents/upload
   ↓
3. Backend 保存文件到本地
   ↓
4. 文档解析（PDF/DOCX/TXT/MD）
   ↓
5. 文本分块（Chunking）
   ↓
6. 生成 Embedding 向量
   ↓
7. 存储到 Qdrant
   ↓
8. 返回上传结果
```

## 📝 配置说明

### 关键配置项

**config.toml**
```toml
[llm]
provider = "カスタム"           # LLM 提供商
api_base = "http://..."         # API 端点
api_key = "your-key"            # API 密钥
model_name = "qwen2.5:7b"       # 模型名称
temperature = 0.7               # 温度参数

[embedding]
provider = "ollama"             # Embedding 提供商
base_url = "http://..."         # Ollama 地址
model_name = "nomic-embed-text" # Embedding 模型
dimension = 768                 # 向量维度

[database]
host = "localhost"              # MySQL 主机
port = 3306                     # MySQL 端口
username = "root"               # 数据库用户
password = "root"               # 数据库密码
database = "chatbot"            # 数据库名称
```
