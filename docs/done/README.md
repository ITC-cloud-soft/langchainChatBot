## 🎯 主要特性

### 核心功能

- ✅ **实时流式对话** - Server-Sent Events 实现
- ✅ **RAG 知识库** - Qdrant 向量检索
- ✅ **多 LLM 支持** - OpenAI、Anthropic、自定义 API
- ✅ **用户权限管理** - JWT + RBAC
- ✅ **会话管理** - 持久化存储和检索

### 技术亮点

- 🚀 **异步架构** - FastAPI + asyncio
- 🎨 **现代前端** - React 18 + TypeScript + Material-UI
- 🐳 **容器化部署** - Docker Compose 一键部署
- 📊 **可观测性** - 健康检查和日志系统

## 🔧 技术栈

### 后端

- Python 3.10+
- FastAPI 0.116.1
- LangChain 0.3.27
- SQLAlchemy 2.0.36
- Qdrant Client 1.10.1

### 前端

- React 18.2.0
- TypeScript 4.9.5
- Material-UI 5.14.1
- Vite 7.0.6

### 基础设施

- MySQL 8.0
- Qdrant (向量数据库)
- Docker & Docker Compose
